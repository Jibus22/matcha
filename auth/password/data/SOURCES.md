# Blocklist sources

`blocklist.txt.gz` is generated by `just blocklist` from the sources below, pinned to one commit each. Every entry is lowercased, stripped of accents, and also stored with digits and symbols trimmed at both ends; entries shorter than 3 letters are dropped.

| Source                                                                                                                  | Content                                                                                                                                             | License                                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords/tree/525f9b560de45753a5ea01069454e72e9aa541c6) | The 50,000 most frequent words in French, English, Spanish, Italian, German and Portuguese, from OpenSubtitles 2018 (`content/2018/<lang>_50k.txt`) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), by Hermit Dave                         |
| [danielmiessler/SecLists](https://github.com/danielmiessler/SecLists/tree/43cbd03be467262ca199816e4d2650c42759fa80)     | `Passwords/Common-Credentials/100k-most-used-passwords-NCSC.txt`, the 100,000 most used passwords published by the UK's NCSC                        | [MIT](https://github.com/danielmiessler/SecLists/blob/43cbd03be467262ca199816e4d2650c42759fa80/LICENSE) |

The blocklist is derived from FrequencyWords' word lists, so it is shared under CC BY-SA 4.0 too.
